# **App Name**: HaulSense

## Core Features:

- Load Entry: Capture essential details for each new trucking load, including mileage, rates, dates, origin, and destination.
- Load Management: View, filter, and edit a comprehensive list of all historical and upcoming loads.
- Pay Period Summary: Generate a detailed breakdown of gross earnings, all deductions, and estimated net pay for any selected period.
- Financial Dashboard: Visualize key financial metrics such as weekly gross pay trends and mileage summaries through interactive charts.
- Configurable Expenses & Deductions: Allow users to define, track, and customize recurring expenses, tax rates, and other variable deductions.
- PDF Report Generation: Export a professional, downloadable PDF summary of any chosen pay period for records or submission.
- AI Expense Categorizer: An AI tool that assists in automatically categorizing inputted expenses and suggesting applicable deductions, learning from user habits and industry norms.
- Set Pay Period: Allows users to set the pay period from Monday to Sunday EST.

## Style Guidelines:

- The visual design will employ a dark color scheme to convey professionalism and readability, especially during low-light use. The background will be a dark, desaturated blue-grey (#151A1D). The primary interactive and branding color will be a clear, deep blue (#36A1F7) representing reliability and progress. A bright cyan (#6FE3E3) will be used as an accent color for highlights and important calls to action, ensuring strong contrast and visibility.
- The application will utilize 'Inter' (sans-serif) for all textual content. This font choice provides a modern, neutral, and highly readable appearance, perfectly suited for the data-intensive and objective nature of financial tracking.
- Icons will be modern, minimalistic, and line-based, ensuring clarity and consistency with the clean UI. They will be used to denote navigation, actions, and data categories without visual clutter.
- The layout will feature a persistent left-hand sidebar for navigation, leading to structured content areas. Data will be presented within distinct cards or sections, utilizing clear labels, precise alignment of values, and generous use of whitespace to enhance readability and data scanning efficiency.
- Subtle, functional animations will be integrated to provide visual feedback for user interactions, data loading states, and transitions between views. These animations will be minimal to maintain a professional and efficient user experience, without causing distractions.
